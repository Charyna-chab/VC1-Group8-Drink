# XING FU CHA - Bubble Tea Ordering System

A PHP web application for a bubble tea shop. It allows users to browse products, add to cart, place orders, manage favorites, provide feedback, and for admins to manage products, orders, users, and view receipts.

## Requirements

- PHP 7.4 or higher
- MySQL 5.7+ 
- Composer (https://getcomposer.org/)
- Web server (Apache, Nginx) or PHP built-in server
